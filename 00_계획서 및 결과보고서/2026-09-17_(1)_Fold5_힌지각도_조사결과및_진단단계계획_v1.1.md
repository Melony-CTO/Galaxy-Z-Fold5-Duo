## 1. 결론 요약

1. **표준 힌지 센서(`TYPE_HINGE_ANGLE`)로는 안 된다.** Fold3/4·Flip5·TriFold·Fold7 모두 0/90/180 같은 계단값만 준다는 보고가 있다. Fold5도 같을 가능성이 높다 (실측 전 미확정).
2. **Fold7 앱이 부드러운 각도를 얻는 방법은 "권한 우회"다.** 삼성 시스템 배경화면(SprWallpaper/FoldInteractive)이 내부적으로 쓰는 각도를 ADB(폰 안의 개발자 연결) 또는 Shizuku로 로그에서 읽는다.
3. **Fold5도 One UI 8.5(Android 16)까지 올라와 있어** 같은 OS 기반 방식이 통할 여지가 있다. 단, 배경화면 엔진 존재 여부·명령 번호·화면 상태 번호는 기기마다 다를 수 있어 **실기기 확인이 먼저**다.
4. 참고 3개 레포는 모두 **MIT 라이선스** — 저작권 고지만 유지하면 재사용 가능.

## 4. 각도 획득 후보 순위 (Fold5)

1. **삼성 벤더 정밀 센서를 Shizuku 셸 권한으로 등록** (Folduo 방식 a) — 있으면 가장 안정·저지연
2. **배경화면 로그 방식** (Z-Fold-Duo-TEST / Folduo b) — 가장 유력한 실전 경로이나 가장 깨지기 쉬움
3. **공개 `TYPE_HINGE_ANGLE`** — 계단값이면 "자세(접힘/반접힘/펼침)" 신호로만 사용
4. **양쪽 가속도계로 각도 추정** — 레포 사례 없음, 최후 수단

## 5. Phase 1 계획 — 실기기 진단 (코드 작성 전)

### 5.1 준비 (맥클)

| 단계 | 작업 | 검증 |
|---|---|---|
| P0-1 | 맥에 adb 설치 (`brew install android-platform-tools`) — **현재 맥클에 adb 없음 확인(2026-09-17)** | `adb version` 출력 |
| P0-2 | Fold5: 설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호 7회 탭 → 개발자 옵션 → 무선 디버깅 ON | 폰에 IP:포트 표시 |
| P0-3 | 맥에서 `adb pair IP:포트` (페어링 코드) → `adb connect IP:포트` | `adb devices` 에 기기 표시 |

### 5.2 진단 명령 (읽기 전용 — 기기 상태를 바꾸지 않음)

| 단계 | 명령 | 알고 싶은 것 |
|---|---|---|
| D1 | `adb shell getprop ro.product.model` / `ro.build.version.release` / `ro.build.PDA` | 모델·Android·펌웨어 |
| D2 | `adb shell dumpsys sensorservice` | 힌지/folding 센서 이름·타입번호·권한 (R5) |
| D3 | `adb shell cmd device_state print-states` | 화면 상태 목록·번호 (R4) |
| D4 | `adb shell dumpsys display` | 내부/커버 디스플레이 ID·해상도 |
| D5 | `adb shell dumpsys wallpaper` | 현재 배경화면 엔진 (R2) |
| D6 | `adb logcat -s SprWallpaper FoldInteractive` 켜둔 채 폰을 천천히 접었다 펴기 | 각도 로그가 연속으로 찍히는지 (R2) |
| D7 | 공개 센서 테스트: 최소 진단 APK(duo-open `HingeAngleSource` 참고) 로 접기 로그 | 계단값인지 연속인지 |

> D1~D6 은 명령만 실행하므로 앱 개발 없이 **오늘 바로** 가능. D7 은 작은 진단 APK 가 필요하며, Android Studio/JDK 설치 확인 후 진행.

## Claude Code 리뷰

- **강점:** 코드 분석(파일:줄 근거)과 외부 조사(링크 근거)를 교차해, Fold5 에서 무엇이 깨질지 R1~R6 으로 구체화했다. 진단 D1~D6 은 기기 상태를 바꾸지 않는 읽기 명령이라 위험이 낮다.
- **리스크:** 가장 유력한 경로(배경화면 로그)는 삼성 내부 구현에 기생하는 방식이라 펌웨어 업데이트 한 번에 깨질 수 있다. 일상 사용 안정성(Level 5)과는 긴장 관계다.
- **미검증:** Fold5 실측 데이터 0건. 참고 레포 3개 빌드 미시도. 레딧·XDA 검색은 범위가 제한적이었다. 삼성 포럼 근거는 검색 스니펫뿐이다.
- **주의:** `cmd device_state state N` 같은 **상태를 바꾸는 명령은 Phase 1 에서 실행하지 않는다.** 강제 종료 시 화면이 꼬일 수 있어 CTO 입회 하에 별도 승인 후 진행한다.
